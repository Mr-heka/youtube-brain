# Community foundation and adaptation

Inspected foundation: `brain-builder`, revision `d6a8697c866ec03ea5353ee089a1c614ac241490`, retrieved 2026-09-12. See [`NOTICE.md`](../NOTICE.md) for attribution and license status.

The foundation repository includes `seed/topic-brain-builder` and its newer `skills/brain-builder`. This establishes the lineage between the old YouTube-oriented builder and the broader community architecture. Individual authorship has not been independently established.

## Adopted

- Organise knowledge around concepts/questions, with a useful index and links between dependent ideas.
- Keep original source material separate from authored knowledge pages.
- Record known gaps and demonstrate answers against the user's questions.
- Separate knowledge from persona/business overlays and project preferences.
- Group source acquisition by family and avoid repeated intake when the brief is complete.

## Retained or strengthened from the existing local builder

- Source hashes, literal caption-span checks, claim-to-cue links and per-source used/excluded records.
- Explicit draft, review, retrieval and calibration distinctions.
- New-destination snapshots, no silent source mutation or automatic refresh date.
- Host-native access/install boundaries and no unsolicited app installation or automatic memory write-back.
- No forced numeric summaries or fixed source quotas; record useful supported specifics.

Community `lint.py` checks structure, not factual support. `verify_numbers.py` checks local numerical consistency, not every figure against its source. This adaptation does not describe either as proof of expertise. The new compiler independently uses the existing evidence verifier and relative links; it does not vendor those scripts or the community ingestion adapters.

## Scope of this rebuild

Upgraded the builder and added a YouTube editing build profile. Offline fixtures test compilation and error handling only. No new editing tutorial, article, podcast or knowledge base was imported; no editing-question benchmark or footage trial was performed. Multi-source ingestion remains an explicit separately inspected tool route; the included automated evidence path is still YouTube captions. Existing reviewed overlay knowledge remains unchanged.

## Format compatibility

This is an architectural adaptation, not a drop-in community brain format. It keeps `sources/` and the local claim ledger rather than community `raw/` and OKF page frontmatter. Use the included local verifier/compiler. Community lint/router/toggle tooling requires a separately tested format translation; it is not claimed compatible with these generated snapshots.
